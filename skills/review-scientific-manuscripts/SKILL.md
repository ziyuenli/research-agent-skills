# Review Scientific Manuscripts

Build every criticism from what the submitted material actually says. Separate observed facts, inference, significance, and requested action.

## Establish the review contract

Identify the manuscript, supplement, journal criteria, requested report sections, anonymity constraints, and the latest reviewer-edited draft. Treat the latest reviewer-edited file as the source of truth. Preserve its deletions and manual changes.

Read [comment-calibration.md](references/comment-calibration.md) before drafting or merging substantive comments.

## Inspect before judging

1. Map the manuscript by page, section, equation, figure, table, and supplement.
2. Recalculate or trace claims that can be checked from supplied material.
3. Mark each proposed criticism as supported, partly supported, unsupported, or unverifiable.
4. Distinguish a contradiction from missing detail, weak justification, ambiguity, or stylistic preference.
5. Label any reconstruction not explicitly stated by the authors as an inference.

## Draft comments

Use four elements:

1. **Location:** stable section, equation, figure, table, or page/line reference.
2. **Observation:** what the manuscript says or shows.
3. **Significance:** why it affects validity, interpretation, reproducibility, or clarity.
4. **Request:** a proportionate, actionable revision.

Avoid asserting “no rationale” when limited rationale exists. State the precise deficiency instead. Do not manufacture citations, errors, experiments, or reviewer consensus.

## Classify and order

- **Major:** threatens validity, reproducibility, central methodology, interpretation, or main conclusions.
- **Minor:** localized clarification, notation, terminology, caption, presentation, or limited justification.

Follow the reviewer's requested classification. Default to the first manuscript location where an issue arises when page order is requested. Renumber and recheck all cross-references after moving or merging comments.

Merge comments only when they address the same underlying defect. Keep framing, methodological integration, factual inconsistency, and language problems separate when their remedies differ.

## Refine an existing review

- Preserve user deletions; do not resurrect comments from an earlier draft.
- Answer explicit reviewer doubts before rewriting their text.
- Scope the output to requested sections only.
- Keep the overall assessment consistent with retained detailed comments.
- Do not silently remove a concern; mark it unsupported and explain why.
- Back up the current reviewer-edited file before any substantive replacement.

## Quality gate

Confirm:

- every criticism maps to visible evidence;
- inferred calculations are labeled;
- page, line, figure, table, and equation references are correct;
- major/minor severity is proportionate;
- requested sections and ordering are respected;
- no deleted comment reappears;
- the overall assessment does not introduce unlisted criticisms;
- the report contains no unsupported factual or scientific claim.
